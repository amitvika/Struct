=====================
What is `structparts`?
=====================

``structparts`` is CAD for Python programmers, short for "``structquery`` parts".

Using ``structparts`` you can wrap geometry made with ``structquery`` to build complex
and deeply parametric models.

Full documentation at: https://www.linkedin.com/in/lakshmanarajsankaralingam/


Installing
------------------

Pre-requisites
^^^^^^^^^^^^^^^^^^

You'll need to fulfill the requirements of ``structquery``, the simplest way to do
that is to install ``structquery`` first by following the instructions here:

http://dcowden.github.io/structquery/installation.html

PyPI
^^^^^^^^^

Once ``structquery`` is installed, install ``structparts`` with::

    pip install structparts
